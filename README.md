# Manuscript preparation scripts

This script flatten the directory structure of manuscript files for submission

## Build

Requirements: Dart SDK.

To build the CLI tool, run the following command in the terminal:
```sh
dart build cli
```

## Usage

To use the CLI tool, run the following command in the terminal:

```sh
dart run bin/manuprep.dart <source-latex-file.tex> <destination_directory>
```
